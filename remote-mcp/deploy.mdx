You can have a publicly accessible MCP server running on Cloudflare Workers in minutes. Choose between the one-click deploy button for the fastest path or the Wrangler CLI for full local control. Either way, your server ends up at a stable `workers.dev` URL that any MCP-compatible client can reach.

## Prerequisites

Before you deploy, make sure you have:

- A [Cloudflare account](https://dash.cloudflare.com/sign-up) (free tier is sufficient)
- **Node.js 18 or later** installed on your machine
- **Wrangler CLI** installed globally:

```bash
npm install -g wrangler
```

## Option A: One-click deploy

Click the **Deploy to Workers** button in the [repository README](https://github.com/Im-Hal-9K/remote-mcp-server-authless) to launch Cloudflare's one-click deploy flow. Cloudflare forks the repository to your account, configures the Worker and Durable Object bindings automatically, and deploys — no local tooling required.

## Option B: Wrangler CLI deploy

<Steps>
  <Step title="Clone or scaffold the project">
    Scaffold a new project directly from the template with a single command:

    ```bash
    npm create cloudflare@latest my-mcp-server -- --template Im-Hal-9K/remote-mcp-server-authless
    ```

    Or clone the repository manually:

    ```bash
    git clone https://github.com/Im-Hal-9K/remote-mcp-server-authless
    cd remote-mcp-server-authless
    npm install
    ```
  </Step>

  <Step title="Log in to Cloudflare">
    Authenticate Wrangler with your Cloudflare account:

    ```bash
    npx wrangler login
    ```

    A browser window opens for you to authorise the CLI.
  </Step>

  <Step title="Deploy to Workers">
    Build and publish your Worker:

    ```bash
    npm run deploy
    ```

    Wrangler compiles your TypeScript, creates the Durable Object namespace, and deploys everything to Cloudflare's edge network.
  </Step>

  <Step title="Confirm your server is live">
    After a successful deploy, Wrangler prints your Worker URL. Your MCP endpoint is live at:

    ```
    https://remote-mcp-server-authless.<your-account>.workers.dev/mcp
    ```

    Any request to a path other than `/mcp` returns a `404`.
  </Step>
</Steps>

## Local development

To run the server on your machine before deploying, start the local dev server:

```bash
npm run dev
```

Your MCP endpoint is available at `http://localhost:8787/mcp`. Wrangler simulates the Durable Object runtime locally, so the behaviour matches production.

## Connect to Claude Desktop

Claude Desktop connects to remote MCP servers through the [`mcp-remote`](https://www.npmjs.com/package/mcp-remote) proxy. Open your Claude Desktop configuration file (`claude_desktop_config.json`) and add the following entry:

```json
{
  "mcpServers": {
    "my-remote-mcp": {
      "command": "npx",
      "args": ["mcp-remote", "https://remote-mcp-server-authless.<your-account>.workers.dev/mcp"]
    }
  }
}
```

Restart Claude Desktop. Your deployed tools appear in the tools panel automatically.

## Connect to Cloudflare AI Playground

The [Cloudflare AI Playground](https://playground.ai.cloudflare.com/) acts as a remote MCP client and can connect directly to your server without any proxy:

1. Go to [https://playground.ai.cloudflare.com/](https://playground.ai.cloudflare.com/).
2. Paste your MCP server URL (`https://remote-mcp-server-authless.<your-account>.workers.dev/mcp`) into the MCP server field.
3. Your tools are now available to the playground's AI models.
