Memory MCP is a Node.js MCP server that gives Claude a durable, searchable memory store that survives across sessions. By default Claude forgets everything when a conversation ends — Memory MCP fixes that by writing memories to a local SQLite database on your machine and surfacing them automatically in future sessions. All data stays on your device; nothing is sent anywhere unless you explicitly enable cloud sync.

## Key features

<CardGroup cols={2}>
  <Card icon="magnifying-glass" title="FTS5 Full-Text Search">
    Memories are indexed with SQLite FTS5 and porter stemming so natural-language queries return relevant results quickly — no embeddings or external services required.
  </Card>
  <Card icon="brain" title="Auto-Summarization">
    Every memory gets a 15–20 word summary generated at store time. Summaries let Claude scan what you know before deciding what full content to load.
  </Card>
  <Card icon="tag" title="Entity Extraction">
    Names, projects, and tools are automatically identified and linked to memories as entities. You can filter searches by entity to retrieve only what's relevant to a specific person or project.
  </Card>
  <Card icon="clock" title="Smart TTL">
    Expiration is tied to importance. Low-importance memories expire in 7 days; high-importance memories last up to a year or are kept permanently. You can always override the default per memory.
  </Card>
  <Card icon="layer-group" title="Token-Aware Recall">
    `memory_recall` returns a compact index of all matching summaries plus full-detail entries for the top results — sized to fit within your token budget so Claude always sees the most useful context without blowing its context window.
  </Card>
  <Card icon="cloud" title="Optional Cloud Sync">
    Connect to [Substratia Pro](https://substratia.io) for cross-device sync, a web dashboard, and automatic backups. Local-only mode collects zero telemetry.
  </Card>
</CardGroup>

## Memory types

Every memory has a `type` that tells Claude how to categorize and use the information:

| Type | Description |
|---|---|
| `fact` | A discrete piece of information — a preference, a configuration value, a project detail. |
| `entity` | A person, organization, project, tool, or other named thing. |
| `relationship` | A connection between two or more entities (e.g. "Alice is the lead on Project Alpha"). |
| `self` | A preference or personal detail about you — coding style, communication preferences, recurring workflows. |

## How search works

When you call `memory_recall`, the query is passed to SQLite FTS5 for full-text matching against stored memory content and summaries. Results are then re-ranked using a hybrid relevance score:

| Signal | Weight |
|---|---|
| Importance | 40% |
| Recency (last accessed) | 30% |
| Access frequency | 20% |
| Base score | 10% |

The token-aware response format returns a compact summary index for all matches, then fills the remaining token budget with full content for the highest-ranked results.

## Database location

Memory MCP stores all data in a single SQLite file on your local machine. The default path depends on your operating system:

| Platform | Default path |
|---|---|
| macOS | `~/.claude-memories/memory.db` |
| Linux | `~/.local/share/claude-memories/memory.db` |
| Windows | `%APPDATA%/claude-memories/memory.db` |

To use a different location, set the `MEMORY_DB_PATH` environment variable to an absolute path. See [Configuration](/memory/configuration) for details.

<Tip>
  The database is a single portable file. Back it up by copying it anywhere — no special tools required.
</Tip>

## MCP tools at a glance

| Tool | Description |
|---|---|
| [`memory_store`](/memory/tools#memory_store) | Store a new memory or update an existing one. Auto-summarizes content, extracts entities, and calculates importance and TTL. |
| [`memory_recall`](/memory/tools#memory_recall) | Search memories using full-text search. Returns a token-aware index plus full details for top matches. |
| [`memory_forget`](/memory/tools#memory_forget) | Soft-delete a memory by ID. Removes it from search results while preserving the audit trail. |
| [`memory_cloud`](/memory/tools#memory_cloud) | Connect to Substratia Cloud, check sync status, or get usage help. Only needed for cross-device sync. |
