Chaos Navigation MCP Tools is a suite of local [Model Context Protocol (MCP)](https://modelcontextprotocol.io) servers that extend Claude with capabilities it lacks out of the box. The suite gives Claude cross-session memory backed by FTS5 full-text search, a bridge to the Capacities personal knowledge management app, and a ready-to-deploy remote MCP server template — all running on your own machine so you stay in control of your data.

## What's in the suite

**Memory MCP** gives Claude persistent, searchable memory using SQLite with FTS5 full-text search — including OR-expansion and prefix wildcards — plus auto-summarization, entity extraction, importance scoring, TTL management, and optional Substratia Cloud sync. Memories persist in a local database and are available to Claude in every future conversation. The server exposes four tools to Claude: `memory_store`, `memory_recall`, `memory_forget`, and `memory_cloud`.

**Python Utilities** are CLI tools that sit alongside the Memory MCP server. Use them to bulk-import markdown folders, import Claude Code session transcripts, search the memory database from the terminal, and export chat logs for archiving or analysis.

**Capacities MCP** bridges Claude to the [Capacities](https://capacities.io) PKM app. Through this server Claude can list your spaces, search across your knowledge base, read individual objects, save weblinks, and create or update daily notes — all without leaving your conversation.

**Remote MCP Server** is a Cloudflare Workers template you can fork and deploy to expose your own authless remote MCP endpoint. It gives you a URL-addressable MCP server you can share or use from any device, without running a local process.

<Note>
  **How MCP works** — MCP (Model Context Protocol) is an open standard that lets AI assistants talk to external tools and data sources. Each server in this suite runs as a local process and communicates with Claude over `stdio`. Claude Desktop and Claude Code discover these servers through a JSON config file, launch them automatically at startup, and expose their tools to Claude during every conversation. No cloud account or special permissions are required for the local servers.
</Note>
