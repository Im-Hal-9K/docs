title: "Install Memory MCP and Connect It to Claude"
sidebarTitle: "Quickstart"

---

The fastest path to persistent memory in Claude is the auto-installer, which locates your config file and adds the server entry for you. If you prefer to configure things by hand, the manual steps are just as quick.

<Steps>
  <Step title="Prerequisites">
    Before you begin, make sure you have the following installed:

    - **Node.js 18+** and **npm** — required to run the Memory MCP server via `npx`
    - **Python 3.x** — required only if you plan to use the Python CLI utilities
    - **Claude Desktop** or **Claude Code** — the MCP servers integrate with either client

    You do not need a cloud account or any API keys to use the local MCP servers.
  </Step>

  <Step title="Install Memory MCP">
    The fastest way to get started is the auto-installer. Run this command in your terminal:

    ```bash
    npx --package @whenmoon-afk/memory-mcp memory-mcp-install
    ```

    The auto-installer locates your `claude_desktop_config.json` file, adds the `memory` server entry automatically, and confirms when it is done. You can skip straight to step 4.

    Alternatively, you can run the server directly to verify it works before configuring Claude:

    ```bash
    npx @whenmoon-afk/memory-mcp
    ```
  </Step>

  <Step title="Manual Claude Desktop configuration">
    If you prefer to configure Claude Desktop by hand, open your `claude_desktop_config.json` file and add the `memory` entry under `mcpServers`:

    ```json
    {
      "mcpServers": {
        "memory": {
          "command": "npx",
          "args": ["-y", "@whenmoon-afk/memory-mcp"]
        }
      }
    }
    ```

    The config file lives in a different location depending on your operating system:

    | OS | Path |
    |----|------|
    | macOS | `~/Library/Application Support/Claude/claude_desktop_config.json` |
    | Linux | `~/.config/Claude/claude_desktop_config.json` |
    | Windows | `%APPDATA%\Claude\claude_desktop_config.json` |

    If the file does not exist yet, create it with the JSON block above as its entire contents.

    <Note>
      **Windows users:** If Claude Desktop reports a "Connection closed" error, wrap the command with `cmd /c`:

      ```json
      {
        "mcpServers": {
          "memory": {
            "command": "cmd",
            "args": ["/c", "npx", "-y", "@whenmoon-afk/memory-mcp"]
          }
        }
      }
      ```
    </Note>
  </Step>

  <Step title="Restart Claude Desktop">
    Save the config file and fully quit Claude Desktop — use **File → Quit** (or ⌘Q on macOS) rather than just closing the window. When you relaunch it, Claude Desktop reads the config and starts the Memory MCP server automatically in the background. You will see the memory tools available in the tool picker once the server is running.
  </Step>

  <Step title="Test it">
    Open a new conversation in Claude Desktop and ask Claude to store a memory:

    > "Remember that my preferred coding language is TypeScript."

    Claude calls the `memory_store` tool and confirms the memory was saved. Then ask it to recall:

    > "What do you remember about my preferences?"

    Claude calls `memory_recall`, searches the local database, and surfaces everything it has stored about you — including the preference you just saved. The memory persists across all future sessions automatically.
  </Step>
</Steps>

## Claude Code slash commands

If you use Claude Code, the Memory MCP server also registers two slash commands you can run directly from the chat input:

| Command | Description |
|---------|-------------|
| `/memory:connect` | Connect to Substratia Cloud for backup and cross-device sync. Run with your API key: `/memory:connect YOUR_API_KEY` |
| `/memory:status` | Show current memory database stats and cloud sync status. |
